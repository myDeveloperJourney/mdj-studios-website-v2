## The problem with generalists

## The one-job test

Write the job as a single sentence that starts with a verb. If a stranger could read it and guess the bot's routines and connectors, it passes.

1. Start with a verb: plan, triage, draft, reconcile, monitor.
2. Name one input and one output.
3. Cut every clause that needs a second connector.
